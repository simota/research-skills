# Question Quality Gate

A brief ships only when every row passes.

| Check | Fails when |
|-------|-----------|
| Answerable | No conceivable evidence would settle it |
| Falsifiable | No finding could overturn the expected answer |
| Bounded | Missing out-of-scope lines, stopping rule, or budget |
| Decomposed | Sub-questions overlap, or one cannot be answered without another's answer being assumed |
| Linked | A sub-question feeds no decision and no deliverable section |
| Neutral | Phrasing presupposes its own conclusion |
| Calibrated | The evidence bar exceeds what the domain has ever produced |
