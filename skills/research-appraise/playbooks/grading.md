# Grading Quick Table

| Question about the source | Pushes toward |
|---------------------------|---------------|
| Did it observe the thing directly, with data you could re-check? | `P1` |
| Does it synthesise many primaries with a disclosed method? | `P2` |
| Is it a single credible report with method or named sourcing disclosed? | `P3` |
| Does it document its own product's behaviour, spec, API, or published pricing? | `P1` for that use |
| Is it informed opinion, a comparative/promotional claim, or a vendor-run measurement of its own product? | `P4` |
| Is it undated **and** unattributed, unresolvably sourced, or plausibly synthetic? | `P5` |
| Is it undated but attributed, or attributed but methodless? | Cap at `P4` |
| Does it disclose no method at all? | Cap at `P4` |
| Do its own citations fail to resolve? | `P5`, exclude |
| Is it the only source, and interest-aligned? | Keep; record `CEILING: Low` as advice to synthesis |
