# Corpus Composition Targets

A corpus is judged by shape, not size. These are composition targets in terms of **source type**;
the provenance tier of each is `research-appraise`'s call, not this skill's.

| Property | Target | Why |
|----------|--------|-----|
| Primary share | >=1 primary record (spec, filing, data, source code, official docs) per load-bearing sub-question | Secondaries drift from what the primary said |
| Independence | >=2 sources with no shared author, funder, or upstream origin | Corroboration requires separable failure |
| Disconfirming share | >=1 counter-source per contested claim | A one-sided corpus produces a one-sided answer |
| Recency spread | Newest + the origin source | The current state and how it got here |
| Perspective spread | Vendor + independent + practitioner where all exist | Each class systematically omits different things |
| Coverage note | Named, always | What this corpus structurally cannot see |
